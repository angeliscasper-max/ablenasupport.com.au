DESIGN BRIEF

Ablena Support — a support worker app

Six worker-facing screens covering Mable's core loop — find shifts, prove trust, get booked, message, check in, get paid — plus three differences: a live compatibility score instead of a static profile, transparent verification badges the participant can see too, and Face ID at every trust moment (login and shift check-in) so identity never rides on a password alone. Every screen is shown in both iOS and Android. Copy stays warm and plain-language even inside the system's technical frame.
